# قدیر پارتنر Native Android V5.4.3.2 FINAL

نسخه نهایی عملکردی پرتال + اتوماسیون:

پرتال مشتری:
- نمایش مبلغ واقعی نوع قیمت هنگام ثبت سفارش
- نمایش قیمت واحد و جمع هر قلم
- کد تخفیف در ثبت سفارش
- نمایش کدهای فعال همان مشتری در اپ
- پشتیبانی از تخفیف درصدی و مبلغ ثابت
- نمایش مبلغ قبل از تخفیف، تخفیف و جمع نهایی
- ارسال کد تخفیف به Backend و اعتبارسنجی نهایی سمت سرور
- نمایش طرح‌ها و کدهای فعال در پیشخوان
- موجودی عددی همچنان برای مشتری مخفی است
- دانلود سریال سفارش تحویل‌شده، جزئیات سفارش و ویرایش پروفایل حفظ شده‌اند

اتوماسیون:
- همان Backend و MySQL نهایی را استفاده می‌کند.
- سفارش‌های ثبت‌شده از وب و اپ بلافاصله در اتوماسیون قابل مشاهده‌اند.
- پیامک سفارش جدید مدیریت توسط Backend انجام می‌شود و وابسته به نسخه APK نیست.

Backend لازم: GhadirPay Web V5.3.2.0 FINAL یا جدیدتر.

نکته:
این بسته از نظر قابلیت‌ها FINAL است، اما برای انتشار عمومی در بازار باید Release Signed
با Keystore دائمی ساخته شود. Workflow همراه این نسخه برای تست، APKهای Debug هر دو Flavor را می‌سازد.

## تغییرات V5.4.3.0
- عدم انتخاب خودکار دستگاه و هشدار تکمیل سفارش.
- ترتیب قیمت‌ها: سریال آزاد، عامل فروش، ثبت در پنل.
- روش‌های پرداخت: نقد، اعتباری با چک، آنلاین.
- پروفایل با عکس محلی، نام شرکت و کدپستی اختیاری.
- پیش‌فاکتور PDF، درخواست لغو سفارش و تماس پشتیبانی 09981638272.
- برگشت صحیح دکمه Back و ورود بیومتریک سازگار با اثرانگشت/چهره دستگاه.
- موجودی/فیلتر/نشان اعتباری در فهرست دستگاه‌ها.


## V5.4.3.1 PERFORMANCE HOTFIX
- درخواست‌های Home به‌صورت موازی انجام می‌شوند.
- Catalog / Offers / Orders / Summary دارای cache کوتاه‌مدت ۱۵ ثانیه‌ای در حافظه هستند؛ هر POST یا Logout cache را پاک می‌کند.
- بارگذاری Catalog و Offers در ثبت سفارش هم‌زمان شده است.
- تصویر لوگوی 1024px به 512px بهینه شد تا Decode اولیه سبک‌تر شود.
- هیچ تغییری در API contract، روش ورود، سفارش، بیومتریک یا داده‌های سرور ایجاد نشده است.


## V5.4.3.2 CUSTOMER PORTAL UPDATE
- خروجی سریال سفارش تحویل‌شده به PDF چندصفحه‌ای داخل Downloads/GhadirPartner.
- در ثبت سفارش هیچ مدل دستگاهی به‌صورت پیش‌فرض انتخاب نمی‌شود و فقط «انتخاب دستگاه» نمایش داده می‌شود.
- عکس پروفایل قابل انتخاب است و در سربرگ پرتال نیز نمایش داده می‌شود.
- وضعیت پشتیبانی بیومتریک در پروفایل نمایش داده می‌شود و رفتار دکمه «ورود با رمز» در BiometricPrompt اصلاح شده است.
- بعد از انتخاب دستگاه هشدار واضح نهایی‌کردن سفارش نمایش داده می‌شود.
- بعد از ثبت سفارش، کاربر مستقیم وارد جزئیات همان سفارش می‌شود و می‌تواند پیش‌فاکتور PDF با اطلاعات همان سفارش دریافت کند.
- روش‌های تسویه پرتال فقط نقد، چک و اعتباری هستند.
- لیست قیمت دارای فیلتر مدل، شرکت سازنده و موجود/ناموجود است.
- قیمت‌های هر دستگاه در دو گروه «سریال آزاد» و «ثبت در پنل» نمایش داده می‌شوند.
- برای گزینه «اعتباری» نصب Patch سازگاری Backend همراه این بسته الزامی است.
