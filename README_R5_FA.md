# قدیر پارتنر Android 5.4.3.3-r5 — نسخه سورس برای ساخت و بررسی

مبنا: سورس R4 همین گفتگو. این بسته APK آماده نیست و روی گوشی رندر یا اجرا نشده است. هیچ نسخه‌ای روی سایت یا GitHub منتشر نشده است.

## تغییرات این تحویل
۱. قفل بیومتریک بعد از رفتن اپ به پس‌زمینه مجدداً فعال می‌شود؛ صفحه زیر قفل در ترکیب رابط باقی می‌ماند تا فرم‌ها و انتخاب عکس از بین نرود. در دسترس نبودن بیومتریک به ورود با رمز برمی‌گردد. آزمون واقعی گوشی لازم است.
۲. افکت شیشه و Blur فقط برای منوی پایین نگه داشته شده؛ بدنه، کارت‌ها و دکمه‌ها رنگ مات و کادر ساده دارند.
۳. پیشخوان یک دکمه کوچک شمارش آفر دارد که صفحه آفرها را باز می‌کند.
۴. کارت سفارش‌ها در پیشخوان و فهرست کوتاه و دو ردیفه شده است.
۵. ظاهر کل اپ با زمینه سرمه‌ای ساده، کارت‌های مات، فاصله کمتر و تأکید نارنجی بازتنظیم شده است. تطابق و کیفیت نهایی نیازمند بازبینی روی گوشی است.
۶. سلام و نام مشتری در کنار سربرگ ۶۴dp قرار گرفته؛ سربرگ بزرگ قبلی حذف شده است.
۷. لیست قیمت ابتدا نوع قیمت، سپس مدل را می‌گیرد و فقط ردیف قیمت انتخاب‌شده را نشان می‌دهد.
۸. ثبت سفارش هم ابتدا نوع قیمت و سپس محصول متناسب با آن را انتخاب می‌کند.
۹. فاکتور رسمی تغییر نکرده است: عکس یا PDF نمونه هنوز دریافت نشده؛ تطبیق دقیق پس از دریافت آن انجام می‌شود.
۱۰. سفارش‌ها بر اساس وضعیت و تسویه فیلتر می‌شوند و جستجو دارند.
۱۱. «سریال‌های من» و «آفرهای من» به پروفایل اضافه شده‌اند.
۱۲. دکمه پشتیبانی شماره ۰۲۱۷۷۲۴۷۰۷۰ را در شماره‌گیر باز می‌کند؛ تماس خودکار برقرار نمی‌کند.
۱۳. سریال و دانلود آن فقط برای سفارش تحویل‌شده نمایش داده می‌شود؛ پاسخ API سفارش هم قبل از تحویل سریال را حذف می‌کند.
۱۴. آدرس‌های متعدد در سرور ذخیره، ویرایش و حذف می‌شوند؛ مشتری هنگام ثبت سفارش انتخاب می‌کند. نسخه آدرس در سفارش ذخیره می‌شود و تغییر بعدی آدرس سفارش قدیمی را تغییر نمی‌دهد. آدرس اصلی پروفایل انتخاب پیش‌فرض است.
۱۵. ثبت سفارش مشتری از ۰۹:۰۰ تا قبل از ۱۸:۰۰ به وقت تهران مجاز است. سرور درخواست خارج از بازه را رد می‌کند؛ بعد از ۱۸ پیام مراجعه فردا ساعت ۹ می‌دهد؛ قبل از ۹ پیام مراجعه امروز ساعت ۹. محدودیت روز تعطیل درخواست نشده و اعمال نشده است.
۱۶. مجموع دستگاه‌های خریداری‌شده در پیشخوان: جمع تعداد اقلام دارای سریال در سفارش‌های تحویل‌شده همین مشتری. اقلام مصرفی، سفارش‌های در جریان و لغوشده در شمارش نیستند.

## نصب و ساخت
ابتدا سرور همراه Web V5.3.4.19 را در محیط آزمایشی، با پشتیبان کامل و حفظ config.php، داده‌ها و آپلودهای موجود نصب کنید. API جدید برای آدرس‌ها و تعداد دستگاه‌ها ضروری است.
محتویات ZIP اندروید را در ریشه مخزن قرار دهید. مسیر app/build.gradle باید مستقیم در ریشه باشد و فایل .github/workflows/build-android-r2.yml هم منتقل شود.
در GitHub Actions، workflow «Build Ghadir Partner Android Compact R5» را روی main اجرا کنید. پس از موفقیت Build و lint، Artifact با نام GhadirPartner-5.4.3.3-R5-Debug-APK را دانلود و استخراج کنید.
خروجی Debug است؛ برای انتشار نهایی کلید امضای ثابت لازم است. cache کلید Debug قبلی حفظ شده ولی تضمین همیشگی امضا نیست؛ اگر امضای APK قبلی فرق دارد بدون بررسی و پشتیبان آن را حذف نکنید.

## اعتبارسنجی
موفق: نحو PHP، مرزهای زمانی تهران ۰۸:۵۹/۰۹:۰۰/۱۷:۵۹/۱۸:۰۰، مالکیت آدرس، ذخیره/حذف آدرس، مستقل‌ماندن snapshot، جداسازی حساب‌ها، پنهان‌سازی سریال پیش از تحویل، شمارش دستگاه‌های تحویل‌شده بدون اقلام مصرفی و حساب دیگر.
بررسی ساختاری Kotlin برای فایل‌های جدید خطای جدید نشان نداد؛ این جای کامپایل را نمی‌گیرد. خطاهای parser موجود در دو فایل قدیمی با نسخه مبنا مشترک‌اند.
انجام نشده: کامپایل اندروید، lint، نصب روی دستگاه، آزمون واقعی قفل بیومتریک، اندازه‌ها و فونت‌ها و چاپ. Gradle/SDK محلی در دسترس نیست. خطای دسترسی نوشتن GitHub در مرحله قبلی مانع ساخت از اینجا بود.
قبل از نصب عملیاتی این مسیرها را روی گوشی بررسی کنید: ورود و قفل پس‌زمینه، انتخاب عکس، قیمت و مدل، سفارش با دو آدرس متفاوت، رد سفارش خارج ساعت، فیلترها، سریال پیش/پس از تحویل و تماس پشتیبانی.
اعلان‌ها همان حالت R4 هنگام باز بودن اپ و بازگشت به آن هستند؛ Push در حالت بسته بودن اضافه نشده است.
راهنماهای قدیمی فقط سوابق‌اند؛ راهنمای جاری همین فایل است.
