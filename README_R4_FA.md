# قدیر پارتنر — Android 5.4.3.3-r4

وضعیت: سورس آماده بررسی و ساخت است؛ APK در این بسته وجود ندارد. تطابق تصویری روی دستگاه، کامپایل اندروید و آزمون بیومتریک هنوز انجام نشده‌اند.

## تغییرات
- زمینه سرمه‌ای و نارنجی، کارت‌ها و دکمه‌های شیشه‌ای و منوی پایین شناور؛ Blur منوی پایین در Android 12 به بالا و حالت نیمه‌شفاف در نسخه‌های قدیمی‌تر.
- زنگوله با شمارنده، پیام‌های مشتری، آفرهای مجاز، وضعیت سفارش، فیلتر، جزئیات و ثبت خوانده‌شدن.
- دسترسی از پیام به سفارش یا آفر و ثبت سفارش با کد طرح؛ انتخاب و حذف عکس پروفایل و کلید بیومتریک.
- منطق موجود ثبت سفارش، تسویه و PDF حفظ شده و مسیر استفاده از آفر اضافه شده است؛ آزمون جامع عملکرد روی دستگاه لازم است.

## نصب بخش سرور
ابتدا بسته Web V5.3.4.18 همراه این تحویل را طبق راهنمای آن نصب کنید. بدون آن مرکز پیام اپ فعال نیست.
مدیر از صفحه کاربران پرتال / کاربران قدیرپارتنر، بخش «ارسال پیام» به همه یا مشتریان منتخب پیام می‌فرستد. آفرهای فعال متناسب با مخاطب خودکار در زنگوله دیده می‌شوند.
اعلان‌ها هنگام ورود، بازگشت به اپ و هر ۶۰ ثانیه در حالت فعال دریافت می‌شوند. این نسخه Push در حالت بسته بودن اپ ندارد.

## ساخت APK توسط GitHub
۱. ZIP سورس Android را استخراج کنید.
۲. محتوای آن را در ریشه مخزن mahantah/ghadirpartner-android-r2 جایگزین و commit کنید؛ خود ZIP یا پوشه والد را آپلود نکنید. فایل app/build.gradle باید در ریشه ساختار app باشد.
۳. فایل workflow همراه بسته در مسیر .github/workflows/build-android-r2.yml قرار دارد؛ از انتقال آن مطمئن شوید.
۴. در Actions گزینه Build Ghadir Partner Android Liquid Glass R4 را باز کنید؛ Run workflow را برای main بزنید.
۵. پس از موفقیت Build و lint، Artifact با نام GhadirPartner-5.4.3.3-R4-Debug-APK را دانلود و استخراج کنید؛ APK داخل آن نسخه آزمایشی است.
۶. نصب را روی دستگاه آزمایشی انجام دهید و ورود، سفارش، پرداخت، PDF، عکس، بیومتریک و زنگوله را بررسی کنید.

این workflow خروجی Debug با شناسه ir.ghadirpartner.portalapp.debug می‌سازد و انتشار فروشگاهی انجام نمی‌دهد. کلید Debug در cache نگهداری می‌شود؛ cache تضمین نگهداری دائمی امضا نیست. برای انتشار نهایی باید کلید امضای ثابت خودتان تنظیم شود. اگر امضای نسخه قبلی متفاوت است، نصب روی آن ممکن نیست؛ بدون پشتیبان داده نسخه قبلی را حذف نکنید.

## محدودیت اعتبارسنجی
آزمون‌های PHP برای مخاطب، تاریخ آفر، مالکیت سفارش، خوانده‌شدن، منع ارسال توسط مشتری و عدم نمایش رمز یک‌بارمصرف موفق بوده‌اند. فرم ارسال مدیر با API آزمایشی در مرورگر آزموده شده است. هیچ پیام واقعی ارسال نشده است.
ساخت APK به علت نبود SDK/Gradle محلی و خطای 403 دسترسی نوشتن GitHub انجام نشده؛ فایل‌های مخزن آنلاین تغییر نکرده‌اند. پیش از نصب عملیاتی سرور، یک نسخه آزمایشی و پشتیبان داشته باشید.
