# اندروید R5.5 — اجرای طراحی Figma 100:573

نسخهٔ 5.4.3.3-r5.5 با versionCode 543055، بر پایهٔ پرتال Native موجود.

طراحی روز و شب شامل پیشخوان، قیمت‌ها، سفارش‌ها، پروفایل، ورود، تسویه و اسناد با Jetpack Compose پیاده‌سازی شده است. لوگو و تصویر آفر از فایل اصلی فیگما استفاده می‌کنند. آیکن‌های منو، جستجو و کنترل‌های سربرگ SVG اصلی‌اند و در دستگاه به تصویر شفاف تبدیل می‌شوند. مشخصات و هش منابع در validation/figma-assets.json ثبت شده‌اند. تصویر بزرگ آفر بدون تغییر در قطعه‌های باینری نگهداری می‌شود؛ ساخت، آن‌ها را ترکیب و SHA-256 را کنترل می‌کند.

گردش ثبت سفارش از انتخاب مدل، نوع خرید و آدرس به تسویهٔ نقدی، چک یا اعتبار، بازبینی و ثبت نهایی می‌رسد. اطلاعات واقعی قیمت و موجودی از API می‌آیند؛ داده‌های نمونهٔ فیگما در محیط اصلی وارد نشده‌اند. خطای دریافت حساب، موجودی یا اعتبار، با پیام قابل بازیابی نمایش داده می‌شود. ارسال اطلاعات تسویه به معنای تأیید مالی یا مجوز ارسال کالا نیست.

ورود با رمز و OTP، بازیابی رمز، بیومتریک، آدرس‌های ذخیره‌شده، درخواست لغو، اعلان‌ها، آفرها، ویرایش پروفایل و PDF پیش‌فاکتور به سرویس‌های موجود متصل‌اند. سریال و IMEI و PDF سریال فقط برای سفارش تحویل‌شده در دسترس‌اند. تصویر پروفایل در دستگاه ذخیره می‌شود. عملیات گزارش و آدرس که در صفحهٔ جدید فیگما نیستند، در خدمات بیشتر حفظ شده‌اند.

تفاوت‌های ناشی از API موجود: تأیید کد بازیابی همراه با ثبت رمز جدید انجام می‌شود؛ بانک و تاریخ چک ورودی متنی‌اند؛ تغییر اطلاعات پروفایل مستقیم توسط سرویس فعلی ذخیره می‌شود. هیچ مرحلهٔ تأیید پشتیبانی یا پرداخت موفق ساختگی نمایش داده نمی‌شود. وضعیت و سقف اعتبار را سرور تعیین می‌کند.

برای ساخت از Java 17، Gradle 8.9 و Android SDK 35 استفاده کنید:
```sh
gradle :app:assemblePortalDebug :app:assemblePortalDebugAndroidTest :app:lintPortalDebug :app:assembleAutomationDebug :app:lintAutomationDebug
```
workflow گیت‌هاب همین بررسی‌ها و شروع/بازگشت برنامه و هفت آزمون Android API 29 را اجرا می‌کند. آزمون‌ها از پاسخ‌های مصنوعی API استفاده می‌کنند و پیامک، سفارش یا پرداخت واقعی نمی‌فرستند. ساخت، lint هر دو flavor، شروع/بازگشت و هفت آزمون برای کامیت 02e3f8e4507789fc217012773d3c9714bc7cd8e5 موفق شدند: [گزارش و APK](https://github.com/mahantah/ghadirpartner-android-r2/actions/runs/38061463799). جزئیات و SHA-256 خروجی در VALIDATION.json ثبت شده‌اند.

تأیید اثر انگشت، دوربین و گردش کامل حساب واقعی روی گوشی هنوز لازم است. API_MATRIX.md وابستگی‌های سرور را توضیح می‌دهد. این تغییر کد سرور را منتشر نمی‌کند.
