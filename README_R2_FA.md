# قدیر پارتنر — Android 5.4.3.3 / Figma R2

مبنای این بسته دقیقاً سورس GhadirPartner-Android-Native-V5.4.3.3-FINAL است.
طراحی مرجع: https://www.figma.com/design/ZlDIZg1KOLT6V1PdHDUPNS?node-id=24-35

تغییرات: رنگ و فونت Vazirmatn، سربرگ، کارت‌ها، دکمه‌های خوانا، چیدمان RTL، نوار شناور با آیکن‌های صادرشده از Figma و لیست قیمت شش‌رده‌ای همیشه باز. فیلتر مدل/سازنده/موجودی پشت دکمه فیلترها حفظ شده است. قیمت و موجودی از سرور می‌آید؛ داده نمونه Figma وارد برنامه نشده است.

قواعد سفارش، پرداخت نقد/چک/اعتبار، محدودیت تعداد، کد تخفیف، بیومتریک، پروفایل و حذف عکس، PDF سریال در مرحله تحویل، پیش‌فاکتور و APIها حفظ شده‌اند. فروش اعتباری و تاریخ به‌روزرسانی محصول نیز حفظ شده است. شماره موجودی داخلی نمایش داده نمی‌شود.

Blur واقعی پس‌زمینه نوار در Android 12 به بالا اجرا می‌شود؛ نسخه‌های قبلی سطح نیمه‌شفاف دارند. متن و دکمه‌های نوار مستقل از لایه Blur هستند.

## وضعیت تحویل
این بسته سورس اصلاح‌شده است، نه APK آزمایش‌شده. کنترل ثابت APIها، فیلدهای درخواست، قواعد کلیدی و فایل‌های هسته پاس شد. ساخت محلی پیش از کامپایل به علت دریافت نشدن Android Gradle Plugin از مخزن Google متوقف شد. تست بصری روی دستگاه انجام نشده است. گزارش VALIDATION.json داخل بسته است.

## ساخت
پروژه را در Android Studio با Java 17 و SDK 35 باز کنید و assemblePortalDebug را اجرا کنید. یا محتویات پروژه را در ریشه مخزن قرار دهید و workflow دستی build-android-r2 را اجرا کنید. خروجی فقط Portal Debug است؛ اتوماسیون APK ساخته نمی‌شود. نام بسته و versionCode و versionName مبنا تغییر نکرده‌اند؛ خروجی Debug همان پسوند .debug و -beta مبنا را دارد. انتشار رسمی به امضای قبلی پروژه و شماره ساخت بالاتر نیاز دارد.

## بررسی روی دستگاه پیش از انتشار
ورود رمز/OTP و بیومتریک؛ فیلتر و قیمت‌ها؛ محدودیت موجودی و کد تخفیف؛ ثبت و هشدار نهایی سفارش؛ روش‌های تسویه؛ PDF سریالِ سفارش تحویل‌شده و پیش‌فاکتور؛ انتخاب/حذف عکس؛ فونت بزرگ، کیبورد، اسکرول و نوار پایین روی Android قدیمی و جدید.
