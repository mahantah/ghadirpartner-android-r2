# اندروید R5.4 — طراحی Figma 100:573

مبنای کد Native R5.3؛ نسخه 5.4.3.3-r5.4 و versionCode 543054.

- رنگ‌ها و کارت‌های روز/شب از صفحه Figma؛ تغییر تم ماندگار، سربرگ لوگو/اعلان/آفر.
- ورود رمز و کد پیامکی با محدودیت تلاش و انقضا؛ بازیابی رمز با تکرار رمز جدید.
- حفظ بیومتریک، آدرس‌های متعدد، فیلتر سفارش و مخفی‌بودن سریال پیش از تحویل.
- فرم رسید/چک/درخواست اعتبار، بازبینی پیش از ثبت، صفحه موفقیت و مراحل تحویل.
- پیش‌فاکتورهای من، PDF رسمی چندصفحه‌ای و اشتراک‌گذاری از طریق FileProvider خصوصی.
- عکس پروفایل از دوربین/گالری، حذف و بازگشت به لوگو.
- داده‌های نمایشی Figma نمونه‌اند؛ سفارش، قیمت، اعتبار و اعلان‌ها از حساب واقعی دریافت می‌شوند.

وصله سرور native-r54 روی نسخه جاری پرتال اعمال می‌شود. اطلاعات تسویه نیازمند بررسی مالی است و وضعیت پرداخت/ارسال را خودکار تغییر نمی‌دهد. اعتبار بدون سقف ثبت‌شده به صورت درخواست بررسی نمایش داده می‌شود.

ساخت: workflow build-android-r2.yml روی main یا شاخهٔ یکپارچه‌سازی؛ درخواست‌های ادغام به main نیز بررسی می‌شوند. کلید Debug از cache قبلی دریافت می‌شود و ماندگاری آن تضمین نیست.

ساخت نسخهٔ R5.4 با کامیت 016e50dbd2d900905218d7793e0cb1dafe2291f3 در ۴ اکتبر ۲۰۲۶ موفق بوده است: [گزارش ساخت و دانلود APK](https://github.com/mahantah/ghadirpartner-android-r2/actions/runs/37201563026). lint، شروع و بازگشت برنامه، سه آزمون شبیه‌ساز شامل ناوبری حساب با API مصنوعی، تم روز/شب، اعتبارسنجی تسویه و تولید PDF چندصفحه‌ای گذرانده شده‌اند. تست‌ها هیچ پیامک یا سفارش واقعی ارسال نمی‌کنند.

تأیید اثر انگشت، دوربین و گردش کامل حساب واقعی روی گوشی هنوز لازم است. وابستگی‌های سرور و گزارش‌های نصب وصله‌ها در API_MATRIX.md آمده‌اند. راهنماهای R4 و R5 سوابق‌اند؛ راهنمای جاری این فایل است.
