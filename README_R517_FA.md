# پرتال 5.4.3.3-r5.17

محاسبهٔ تخفیف برای طرح‌های دارای چند کالای منتخب، فقط از ردیف‌های همان کالاها استفاده می‌کند؛ طرح‌های قدیمی تک‌کالا و همه‌کالا همان معنی قبلی را دارند. درخواست‌های پرتال پشتیبانی از محدودهٔ چندکالا را به سرور اعلام می‌کنند. سرور برای جلوگیری از نمایش مبلغ اشتباه، طرح چندکالا را به نسخه‌های قدیمی فاقد این قابلیت نشان نمی‌دهد. شماره ساخت 543067 و همان کلید مالک r5.12 تا r5.16 است. بستهٔ اتوماسیون ساخته و تحویل نمی‌شود.
