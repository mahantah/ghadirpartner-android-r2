# به‌روزرسانی قدیر پارتنر در بازار

مبنای پیاده‌سازی: [مستند رسمی API پیشخان بازار](https://developers.cafebazaar.ir/fa/guidelines/feature/pishkhan-api).
متن همین راهنما از [منبع رسمی محتوای سایت](https://developers.cafebazaar.ir/wp-json/wp/v2/document/3731) نیز قابل دریافت است.
این ابزار مخصوص انتشار است؛ کلید پیشخان و کد انتشار داخل APK قرار نمی‌گیرند. پرداخت سفارش و شارژ کیف پول همچنان از مسیر فعلی انجام می‌شوند.

## یک‌بار تنظیم Secrets

در مخزن GitHub از مسیر Settings → Secrets and variables → Actions سه Secret زیر را بسازید:

| نام | مقدار |
|---|---|
| `CAFEBAZAAR_PISHKHAN_API_SECRET` | توکن مخصوص برنامهٔ `ir.ghadirpartner.portalapp` از منوی «API پیشخان بازار» |
| `GHADIR_RELEASE_KEYSTORE_BASE64` | نمایش Base64 فایل کلید امضای فعلی برنامه، بدون تغییر کلید |
| `GHADIR_RELEASE_KEYSTORE_PASSWORD` | رمز همان کلید فعلی |

هیچ‌یک از مقادیر را در کد، فایل YAML، توضیحات رهانش یا لاگ قرار ندهید. مقدار توکن باید متعلق به همین برنامه باشد؛ API آن را مبنای تشخیص برنامه قرار می‌دهد. امضا و نام بستهٔ APK پیش از هر ارسال بررسی می‌شوند. دسترسی لازم برای تنظیم Secrets با ابزار فعلی فراهم نیست؛ این تنظیم از حساب مالک مخزن انجام می‌شود.

## هر نسخهٔ جدید

۱. نسخه و کد افزایشی را در `config/order-flow.yaml` تنظیم کنید؛ توضیحات انتشار و درصد انتشار در `config/bazaar-release.yaml` هستند.
۲. آزمون‌ها و ساخت Android را تکمیل کنید و SHA دقیق commit آمادهٔ انتشار را بردارید.
۳. در Actions گردش‌کار `Prepare and submit Cafe Bazaar APK` را اجرا کنید. ورودی `source_sha` باید SHA کامل همان commit باشد. برنامه از همان commit ساخته می‌شود، حتی اگر شاخه بعداً تغییر کند.
۴. عملیات مناسب را انتخاب کنید:

| عملیات | نتیجه |
|---|---|
| `dry-run` | ساخت، امضا و بررسی محلی؛ هیچ درخواست به بازار نمی‌فرستد و توکن بازار لازم ندارد |
| `draft` | ایجاد/استفادهٔ مجدد از پیش‌نویس همین APK و بارگذاری؛ برای بررسی ارسال نمی‌شود |
| `review` | بارگذاری و ارسال برای بررسی با `auto_publish=false`؛ انتشار نهایی از پیشخان |
| `publish` | بارگذاری و ارسال برای بررسی با `auto_publish=true`؛ پس از تأیید بازار خودکار منتشر می‌شود |

فایل نصب امضاشده در Artifact با نام `GhadirPartner-Signed-Bazaar-APK` موجود است. فقط فعال‌کردن گردش‌کار، به معنی انتشار در بازار نیست. پیش‌نویس متفاوت حذف یا جایگزین نمی‌شود. پس از قطع ارتباط یا خطای ۴۲۹، ابتدا وضعیت رهانش در پیشخان را بررسی کنید؛ ابزار درخواست‌های نوشتنی را خودکار تکرار نمی‌کند.

این مسیر از APK استفاده می‌کند. انتشار AAB نیازمند مرحلهٔ BIN و سازوکار امضای باندل بازار است و در این ابزار فعال نشده است.

## اجرای محلی ابزار

```bash
python -m pip install -r release_tools/requirements-dev.txt
bash validation/check-release-tools.sh
python -m release_tools --apk /path/to/signed.apk --aapt /path/to/aapt --apksigner /path/to/apksigner --operation dry-run
```

برای `draft`/`review`/`publish` توکن را از محیط امن در متغیر `CAFEBAZAAR_PISHKHAN_API_SECRET` فراهم کنید. ابزار نام بسته، کد/نام نسخه، غیرقابل‌دیباگ بودن و گواهی امضای ثابت را بررسی می‌کند و سپس نتیجهٔ بارگذاری را با SHA-1 فایل محلی تطبیق می‌دهد. اگر نسخه قبلاً برای بررسی ارسال شده باشد، متوقف می‌شود.
