# بازطراحی رابط کاربری برای بررسی

مبنا: نسخه r5.43، commit 723bf21ce4d2b0765adc7f645fa7395f32a19960.

- دسته‌بندی بالای قیمت‌ها حذف و همان انتخاب به پنل فیلتر پایین منتقل شد؛ تمام جدول‌های قیمت و منطق انتخاب قیمت حفظ شد.
- آیکون برداری کارت‌خوان سیار دارای رسید، نمایشگر و صفحه کلید، جای صندوق فروشگاهی را گرفت.
- سفارش رهاشده با فاصله و عنوان کوچک‌تر، همراه با توضیح اعتبار زمانی، اقلام و هر دو عملیات باقی است.
- خلاصه ثابت جمع سفارش به یک سطر با دکمه ادامه تبدیل شد. مرحله تحویل و بسته‌ها و محاسبات تغییری ندارند.
- کارت کیف پول سرمه‌ای و نارنجی، شامل همان موجودی، قابل استفاده و رزروشده است. اعتبار و گردش حساب مستقل باقی ماند.
- ورود و OTP دارای قاب و نشان مشترک، فونت فعلی و نوار بارگذاری هستند. حالت‌های رمز، بیومتریک، بازیابی، عضویت و خطا حفظ شدند.
- مشخصات، تاریخ، وضعیت و مشتری در بالای جزئیات قرار دارند؛ محصولات از ابتدا باز هستند. تمام شرایط قبلی پرداخت، اصلاح، مدارک، اعتبار، تحویل، رسید ارسال، لغو و PDF حفظ شده‌اند.

این شاخه فقط برای بررسی است. هیچ ادغام، امضای انتشار یا ارسال به بازار در این تغییر اجرا نمی‌شود.

بررسی: همان ماتریس موجود Android API 29/35/36، آزمون واحد، Android Lint، ساخت debug/release و تست‌های دستگاه با داده‌های ساختگی. تصاویر واقعی تست در UI-Build-Reports هر API ذخیره می‌شوند.
